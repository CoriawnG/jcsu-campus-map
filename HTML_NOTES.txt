# HTML Notes For JCSU Map Project

File explained:
index.html

Big idea:
This HTML file builds the structure for the JCSU Campus Navigation app.
It creates the intro screen, header, search panel, directions panel, map area, help modal, safety modal, feedback form, and script connections.

HTML = structure
CSS = visual design
JavaScript = behavior and interactivity
Leaflet = the map library

============================================================
1. Document Setup
============================================================

<!DOCTYPE html>

This tells the browser to use modern HTML.

<html lang="en">

This starts the HTML page.
lang="en" means the page language is English.

<head>

The head contains information about the page.
Most of this does not show directly on the screen.

<meta charset="UTF-8">

This lets the browser understand normal text, punctuation, and symbols.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

This helps the layout fit mobile screens and desktop screens.
Without this, phones may render the page too zoomed out.

<title>JCSU Campus Navigation</title>

This is the text shown in the browser tab.

============================================================
2. Mobile App / PWA Settings
============================================================

<meta name="theme-color" content="#002d56">

This sets the browser/mobile theme color.
On phones, it can affect the top browser bar color.

<meta name="apple-mobile-web-app-capable" content="yes">

This helps the app behave more like an installed app on Apple devices.

<meta name="apple-mobile-web-app-title" content="JCSU Map">

This sets the app name if someone saves it to an iPhone home screen.

<link rel="manifest" href="manifest.json">

This connects the web app manifest.
The manifest contains app install information like name, icons, and display settings.

<link rel="apple-touch-icon" href="icons/icon-192.png">

This sets the icon used when the app is saved to an Apple device home screen.

============================================================
3. Stylesheets
============================================================

<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">

This loads Leaflet's CSS.
Leaflet is the map library used to display the interactive map.
The CSS makes Leaflet map controls and tiles display correctly.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,500,1,0">

This loads Google's Material Symbols icon font.
That is why the app can show icons like search, directions, safety, and location.

<link rel="stylesheet" href="style.css?v=20260810-my-places-remove-fix">

This loads your app's custom CSS.
style.css controls the page layout, colors, panels, modals, map buttons, and mobile behavior.

The ?v=... part is a cache-busting version string.
It helps force the browser to load the newest CSS instead of an older cached copy.

22. Important HTML Concepts In This Project
============================================================

id
An id names one exact element.
JavaScript often uses ids to find elements.
Example:
id="locationSearch"

class
A class is mostly for CSS styling.
Many elements can share the same class.
Example:
class="primary-button"

data attributes
Custom values stored in HTML for JavaScript to read.
Example:
data-layer="Academic Buildings"
data-safety-route="Administrative Cottage #4 (Campus Police)"

aria attributes
Accessibility information for screen readers.
Example:
aria-label
aria-live
aria-hidden
aria-expanded
aria-modal
aria-labelledby

hidden
Makes an element invisible until JavaScript shows it.

button type="button"
Makes a button behave like a normal clickable button instead of submitting a form.

form
Groups inputs for submission.

label for="..."
Connects visible label text to an input.

input
A one-line field.

textarea
A larger text field.

select and option
A dropdown menu.

datalist
A list of autocomplete suggestions for an input.

23. How The App Works As A Whole
============================================================

1. HTML creates empty containers and buttons.
2. CSS styles the page so it looks like an app.
3. Leaflet creates the interactive map inside navigationMap.
4. locations.js provides campus places.
5. paths.js provides route/path information.
6. navigation.js helps calculate directions.
7. script.js connects everything together.

Example pattern:

HTML creates this:
<div id="locationResults"></div>

JavaScript finds it and fills it with search results.

HTML creates this:
<button id="getDirections">Get Directions</button>

JavaScript listens for a click and then calculates directions.

HTML creates this:
<div id="navigationMap"></div>

Leaflet uses it to draw the map.
